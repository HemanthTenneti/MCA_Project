How much does prediction help?

Each strategy sees the same trace and starts with cold tables. Correct next-address predictions include both direction and target correctness.

What do these measurements mean?

Direction and target

Direction asks whether a branch is taken. The target buffer remembers where to jump. A correct direction can still produce a wrong next address if its target is missing or stale.

CPI and redirects

A redirect corrects a wrong saved next address. Estimated cycles per instruction (CPI) adds the assumed recovery cost to base CPI. Lower is better. It is an analytical model, not measured CPU execution.

The same strategies can behave very differently across workloads. An alternating pattern and target collisions are useful counterexamples.

What the hardware does

The history table predicts taken or not taken. The target buffer supplies a remembered destination. Selection chooses that destination only when both agree that a usable taken prediction exists; otherwise it chooses PC + 4. Recovery compares the saved choice with the actual next address.
